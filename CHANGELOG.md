## [2.7.0] — 2026-11-22

### ✨ Added
- 🐺 **WOLF AI** — Smart assistant powered by Gemini/z.ai
- 👑 **Empire Drawer** — Admin tools with crown branding
- 🎫 **Ticket system** — Full support ticket workflow
- 💾 **Backup & restore** — One-click backup
- 📊 **Live statistics** — Real-time user count via Durable Objects
- 🔔 **Telegram bot** — Notifications and ticket alerts
- 🌐 **Multi-platform support** — Cloudflare Workers, Katabump, VPS, Docker
- 🎨 **Neon Fantasy Empire theme** — Gold/purple/neon green
- 📱 **Responsive design** — Works on mobile, tablet, desktop
- 🇮🇷 **Persian RTL UI** — Full right-to-left support
- 🤖 **GitHub Actions** — Auto-renewal for Katabump, CI/CD pipeline
- 📖 **Comprehensive docs** — 8 deployment guides
- 🔒 **Security policy** — Vulnerability reporting

### 🔄 Changed
- Refactored worker to support Node.js via Miniflare
- Improved subscription page design
- Enhanced admin dashboard with quick actions

### 🐛 Fixed
- Fixed login redirect on custom domains
- Fixed KV persistence on Katabump
- Fixed WebSocket upgrade handling
